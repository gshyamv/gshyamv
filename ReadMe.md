### 🌟 Featured Projects

#### 🧾 [BillDesk: Agentic Invoice Ingestion & Audit Pipeline](#)
Multi-agent invoice processing system built on a **LangGraph cyclic state machine**, using **IBM Docling VLM** and **vLLM** for document classification and structured extraction. Includes a self-correcting audit engine with **pgvector** semantic search for duplicate detection, served via **FastAPI** with a **React** analytics dashboard.

#### 🗣️ Multilingual VAD-Guided Speech Emotion Recognition
A multi-task, multimodal SER framework fusing audio and text through a **novel VAD-guided cross-attention mechanism**, combining **emotion2vec**, **mBERT**, and Adaptive Modality Gating — achieving state-of-the-art results across 5 multilingual datasets.

#### 🚦 Intelligent Traffic Surveillance & Violation Detection System
End-to-end traffic monitoring pipeline with **YOLOv8** detection, **DeepSORT** multi-object tracking, and **EasyOCR**-based ANPR. Detects overspeeding violations with structured DB logging and a real-time analytics dashboard.

#### ⚡ FPGA Implementation of MobileNet for Solar Cell Defect Classification
Designed four custom IP kernels (Convolution, Depthwise, Pointwise, Batch Norm) using **Vitis HLS**, deployed on a **ZYNQ-ZCU104** board with an AXI-Lite hardware–software co-design. Findings published in the **ASME JCISE Journal**.
